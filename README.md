# RAScal 5 — Калькулятор и конвертер кодов чисел

**RAScal 5** — приложение с графическим интерфейсом (GUI) на Python, разработанное в рамках работы в семестре по дисциплине Основы Программной Инженерии в РГРТУ и предназначенное для перевода чисел между десятичной системой счисления и машинным представлением (прямой, обратный и дополнительный коды в двоичной и шестнадцатеричной системах счисления).

---

## Основные возможности

1. **Перевод из десятичного числа в коды:**
   * Получение прямого, обратного и дополнительного кодов одновременно.
   * Вывод результатов в двоичной и шестнадцатеричной системах счисления.
   * Автоматическое дополнение до нужной разрядности (байт, слово, двойное слово, учетверенное слово — до 64 бит).

2. **Перевод из кодов в десятичное число:**
   * Поддержка ввода из двоичной системы.
   * Поддержка ввода из шестнадцатеричной системы.
   * Выбор типа исходного кода: прямой, обратный или дополнительный.

3. **Удобство использования и валидация:**
   * Встроенная система проверки корректности ввода (диапазоны, недопустимые символы, проверка знаковых битов).
   * Информативные всплывающие окна с ошибками.
   * Встроенный справка-справочник с пошаговым примером перевода чисел.

---

## Структура проекта

* `RAScal_5_MAIN.py` — Главный модуль приложения. Отвечает за отрисовку GUI (Tkinter), управление виджетами, вызов функций перевода и вывод результатов в таблицу (`Treeview`).
* `RAScal_5_INPUT.py` — Модуль валидации ввода. Проверяет синтаксис чисел, диапазоны (от $-(2^{63} - 1)$ до $2^{63} - 1$), корректность двоичных и шестнадцатеричных кодов, а также возвращает коды ошибок.
* `RAScal_5_CONVERT.py` — Модуль-диспетчер. Распределяет логику конвертации в зависимости от выбранных пользователем параметров (направление перевода и тип кода).
* `RAScal_5_DEC_FUNC.py` — Функции перевода из 10-ичной системы в коды. Содержит алгоритмы формирования прямого, обратного и дополнительного кодов, выравнивание по байтовой сетке и перевод в Hex.
* `RAScal_5_CODE_FUNC.py` — Функции перевода из кодов в 10-ичную систему. Реализует обратное преобразование двоичных кодов в десятичные целые числа.
* `RAScal_5_TESTS.py` — Модульные тесты. Набор unit-тестов (`unittest`) для проверки корректности всех вычислительных функций и валидатора ввода.

## Требования и зависимости

* **Python**: версия 3.10 или выше.
* **Библиотеки**: Стандартные библиотеки Python:
  * `tkinter` (со стандартным модулем `idlelib.tooltip`)
  * `unittest`

## Запуск

Убедитесь, что в директории с проектом находятся изображения иконок:
* `RAScal-logo.png` — логотип приложения.
* `ReferImage.png` — иконка кнопки справки.

Запустите главный файл через терминал или командную строку:

```bash
python RAScal_5_MAIN.py
```

---

## Запуск тестов

Для проверки работоспособности всех функций перевода и валидации выполните тесты командой:

```bash
python -m unittest RAScal_5_TESTS.py
```
